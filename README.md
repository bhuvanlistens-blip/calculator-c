# calculator-c

A command-line calculator written in C11, built to practice clean C fundamentals, compiler warnings, and input validation.

## Features

- Basic arithmetic operations: Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`)
- Numeric input validation using `scanf` return-value checking
- Division-by-zero protection
- Operator handling via `switch-case`

## Prerequisites

- A C11-compatible compiler (`clang` or `gcc`)
- On macOS, install Apple Command Line Tools if not already installed:
  ```bash
  xcode-select --install
